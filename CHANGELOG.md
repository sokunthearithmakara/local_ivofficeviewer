# Changelog

All notable changes to this project will be documented in this file.

## [1.3+] - 2026-06-08

- Require Interactive Video 1.8.1+ (2026060800).

## [1.3] - 2026-05-26

- Added Flexbook support with drag-and-drop for office document types.
- Added external document URL support as an alternative to uploading a local file.
- Added Office 365 and Google Drive viewer options.
- Refactored form elements into a PHP helper class with validation.
- Added `db/upgrade.php` to register the content type in Flexbook on upgrade.
- Updated CI workflow to match mod_flexbook (Moodle 4.05–5.02 matrix).
- Moodle 5.2 support.

## [1.2] - 2026-01-16

- Added preloadstrings option.
